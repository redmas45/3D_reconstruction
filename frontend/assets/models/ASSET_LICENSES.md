# Browser animation assets

The reconstruction viewer uses the following vendored runtime assets:

- `humans/reconstruction-human.glb` and `humans/reconstruction-human-female.glb` are
  from the Mesh2Motion human model set. Mesh2Motion publishes the art assets under
  CC0 and the application code under MIT: <https://github.com/Mesh2Motion/mesh2motion-app>.
- `animations/human-base-animations.glb` is from the same Mesh2Motion animation set
  and is distributed with the project under the same asset terms.
- `scripts/three/` contains the Three.js r169 runtime and official addons. Three.js
  is distributed under the MIT license: <https://github.com/mrdoob/three.js>.

The actors are intentionally stylized. They are animation evidence visualizations,
not recovered photographs or a claim of hidden ground truth.
